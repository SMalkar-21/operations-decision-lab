OPERATIONS DECISION LAB — LINK TROUBLESHOOTING

This folder is the interactive website. The main file is index.html.
It is a self-directed portfolio demonstration using SYNTHETIC data.

TO OPEN LOCALLY:
1. Extract the ZIP fully (do not open the HTML while it is still inside the ZIP).
2. Keep the folders data, evidence and technical alongside index.html and portfolio.pdf.
3. Double-click index.html to open it in Chrome, Edge, Safari or Firefox.
4. Change the dashboard filters and test the 'Download 9-page PDF' and 'View SQL queries' links.

TO SHARE A PUBLIC LINK WITH RECRUITERS:
1. Sign in to GitHub and create a PUBLIC repository named operations-decision-lab.
2. Upload the CONTENTS of this folder to the root of the repository, preserving folders and file names.
3. Go to repository Settings > Pages > Build and deployment.
4. Set Source to 'Deploy from a branch', select main and /(root), and Save.
5. Use the 'Visit site' link shown by GitHub once the page has deployed.
6. Test the live URL in an incognito/private browser window before posting to LinkedIn.

IMPORTANT:
- A sandbox:/ file link is a ChatGPT download link, not a public website address.
- Opening HTML in ChatGPT's preview can be blocked; download and extract the ZIP instead.
- This site is not a native .pbix Power BI report.
- The data, pilot scenarios, and results are simulated, not employer outcomes.
