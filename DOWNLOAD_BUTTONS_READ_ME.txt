# Read me first — Download buttons repaired

This edition fixes the three footer controls: Download PDF, Open PDF, and Download technical evidence.

1. Extract the ZIP completely.
2. Open `index.html` with Chrome, Edge, or Firefox.
3. Click **Download the nine-page portfolio PDF** for a local PDF download.
4. Click **Open PDF** to view the PDF in an in-page overlay (no pop-up).
5. Click **Download technical evidence** for the ZIP of SQL, Python, DAX, testing and synthetic data.

These three controls now also work from the standalone HTML file because the resources are embedded in the HTML. Separate `portfolio.pdf` and `technical_evidence.zip` files remain included for direct access.

If you want a public LinkedIn link, upload this folder's CONTENTS to a GitHub repository and enable GitHub Pages from the `main` branch and repository root. The website URL—not the GitHub source file preview—is the public dashboard.

Browser sandboxing: ChatGPT's HTML preview and some in-app browsers block downloads even for valid sites. In that case download the ZIP and open it directly using a normal web browser or your GitHub Pages URL.

All data are synthetic and the June 2025–August 2026 dates are a simulated reporting period.
